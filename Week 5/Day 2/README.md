# Week 5 - Day 2: Prompt Engineering & System Prompts

## Objective
Learn how to control LLM responses using prompt engineering and system prompts with Ollama.

## Tasks Completed
- Connected Python with Ollama API
- Used custom system prompts
- Created prompt templates
- Compared different prompting styles
- Tested multiple prompts

## Models Used
- llama3.2:3b
- qwen2.5:3b

## Technologies
- Python
- Ollama
- Requests

## Results

Different system prompts produced different response styles:

- Teacher → Simple explanations
- Programmer → Technical with code
- Interviewer → Interactive questioning

## Conclusion

System prompts significantly influence the quality, tone, and format of LLM responses.
