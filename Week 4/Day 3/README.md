# Week 4 - Day 3

## Model Serialization – Joblib & Pickle

This project trains a Logistic Regression classifier and demonstrates how to save and reload the trained model using both Joblib and Pickle.

## Objectives

- Train a machine learning model
- Save using Joblib
- Save using Pickle
- Reload serialized models
- Verify identical predictions
- Track experiments with MLflow
