# Week 4 - Day 4

## FastAPI Model Serving Endpoint

This project demonstrates how to deploy a trained Logistic Regression model using FastAPI.

### Features

- Train Logistic Regression model
- Save model using Joblib
- Serve predictions using FastAPI
- Interactive Swagger documentation
- MLflow experiment tracking

### AI/ML 3M Stack

- CrewAI (workflow reference)
- LangGraph (pipeline planning)
- MLflow (experiment tracking)
- MLOps (deployment and versioning)
- Ragas (not required)

### API Endpoints

- GET `/`
- POST `/predict`

### Outputs

- logistic_model.pkl
- FastAPI endpoint
- Swagger UI
- MLflow experiment
