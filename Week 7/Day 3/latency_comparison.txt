4. OBSERVATION
--------------

Both LlamaIndex VectorStoreIndex and ChromaDB were tested
using the same 5 documents and the same 10 queries.

The latency of each query was measured and the average
latency was calculated.

The In-Memory Vector Store stores vectors during the current
program execution, while ChromaDB provides persistent
vector storage.

The latency values were compared to observe the performance
difference between the two vector storage approaches.
